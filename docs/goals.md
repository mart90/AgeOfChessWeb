# Project Goals

## What this is

Web client + server for **Goldrush Gambit**, a chess variant designed by Mart (rules:
[game-rules.md](game-rules.md)). All code was written by Claude. Live at
https://goldrushgambit.com (deployed with `deploy.py` to a Linux box with nginx).

- `AgeOfChess.Server/` — ASP.NET Core 9, EF Core + MySQL, SignalR. Authoritative game logic in
  `GameLogic/`.
- `client/` — Svelte 5 + Vite SPA; built into `AgeOfChess.Server/wwwroot/`.
- `policyNetwork/` — Python/PyTorch experiments for a neural-network bot (paused).
- The old MonoGame desktop repo (`C:\Users\Mart\source\repos\AgeOfChess`) is **not used**.

## Goals

1. **Public release.** The site works but few people know about it. Release publicly once the
   game is attractive to newcomers.
2. **Play against the computer (current focus, prerequisite for release).** New players need an
   opponent that is available at all times and plays reasonably well.
   - The current bot (JS brute-force negamax, `client/src/lib/analysis.js`) is weak and slow.
   - The neural-network attempt (`policyNetwork/`) never got anywhere near good enough.
3. **Possibly resume NN training with a new approach** — e.g. bootstrap from games generated by
   a (much improved) search engine instead of from random/heuristic self-play.
